\chapter*{ВВЕДЕНИЕ}
\label{chap:intro}

Интеллектуальный анализ данных и машинное обучение во многих случаях опираются на решение сложных оптимизационных задач. Кластеризация, упорядочивание матриц, сопоставление графов и другие процедуры могут быть сведены к квадратичной задаче о назначениях (Quadratic Assignment Problem, QAP). QAP является NP-трудной, и точные методы для неё неработоспособны уже при умеренных размерностях, что стимулирует разработку приближённых метаэвристических подходов.

Эволюционные алгоритмы, имитирующие механизмы естественного отбора, хорошо зарекомендовали себя в глобальной оптимизации благодаря способности обходить локальные оптимумы и естественной параллелизуемости. Их применение к QAP позволяет одновременно решать фундаментальную комбинаторную проблему и отрабатывать методы, переносимые на более широкий класс задач анализа данных. Таким образом, исследование и разработка эволюционных алгоритмов, ориентированных на QAP, представляют собой актуальную научно-практическую проблему.

\textbf{Объект исследования} — эволюционные алгоритмы и их применение в задачах анализа данных.

\textbf{Предмет исследования} — гибридные эволюционные алгоритмы, включающие механизмы имитации отжига и специализированные операторы скрещивания, применительно к квадратичной задаче о назначениях как представительной модели анализа данных.

\textbf{Цель работы} — разработка, программная реализация и экспериментальное исследование эволюционного алгоритма для решения квадратичной задачи о назначениях, интерпретируемой как задача кластеризации и упорядочивания объектов анализа данных, обеспечивающего высокое качество решений за приемлемое время.

Для достижения поставленной цели формулируются следующие \textbf{задачи}:
\begin{enumerate}
\item Провести систематический анализ роли оптимизационных задач в анализе данных и обосновать использование квадратичной задачи о назначениях в качестве модельной.
\item Изучить принципы построения эволюционных (генетических) алгоритмов и алгоритмов имитации отжига, обосновать выбор вычислительной схемы применительно к QAP.
\item Разработать способ кодирования решений и специализированные генетические операторы (скрещивания, мутации), гарантирующие допустимость перестановочного представления.
\item Реализовать эволюционный алгоритм, в том числе с элементами имитации отжига в качестве локального улучшения (меметический алгоритм), в виде программного модуля.
\item Провести вычислительные эксперименты на стандартных тестовых примерах, исследовать влияние конфигурационных параметров алгоритма на точность и время вычислений, оценить его работоспособность и границы применимости.
\end{enumerate}

\textbf{Научная новизна} работы заключается в разработке проблемно-ориентированного эволюционного алгоритма для QAP как представительной задачи анализа данных, включающего:
\begin{itemize}
\item способ представления решения, естественно отражающий структуру задачи кластеризации;
\item специализированные операторы вариации, в том числе оптимальное цикловое скрещивание, теоретически максимизирующее расстояние Хэмминга до родителей;
\item схему гибридизации с адаптивным локальным поиском на основе имитации отжига, ускоряющую сходимость популяции.
\end{itemize}

Квадратичная задача о назначениях формулируется следующим образом: для заданных матриц потоков $\mathbf{F}$ и расстояний $\mathbf{D}$ размера $n\times n$ требуется найти перестановку $\pi$, минимизирующую
\[
\min_{\pi \in S_n} \sum_{i=1}^n \sum_{j=1}^n F_{ij} \, D_{\pi(i)\,\pi(j)}.
\]
В анализе данных QAP естественно возникает при сериации матриц, сопоставлении графов, дискретном многомерном шкалировании и других задачах, где необходимо оптимальное упорядочение или назначение объектов с учётом попарных взаимодействий. В силу NP-трудности точные алгоритмы применимы лишь для $n\le 30\text{--}40$; для практических задач основным инструментом служат метаэвристики, в том числе эволюционные и гибридные алгоритмы.

\chapter{Эволюционные алгоритмы в задачах анализа данных: теоретические аспекты}
\section{Задачи анализа данных как оптимизационные проблемы}

Интеллектуальный анализ данных охватывает множество методов, значительная часть которых может быть сформулирована в виде задач математической оптимизации. К числу наиболее известных относятся:
\begin{itemize}
\item \textbf{Кластеризация} — разбиение множества объектов на группы (кластеры) таким образом, чтобы объекты внутри одного кластера были максимально схожи, а объекты из разных кластеров — максимально различны. Критерий качества кластеризации часто выражается суммой попарных расстояний или сходств, что приводит к комбинаторной задаче, NP-трудной в общем случае.
\item \textbf{Выбор признаков} — отбор подмножества наиболее информативных переменных, максимизирующего предсказательную способность модели. Полный перебор подмножеств требует экспоненциального времени, что делает актуальными метаэвристические подходы.
\item \textbf{Снижение размерности и визуализация} — представление многомерных данных в пространстве меньшей размерности с сохранением структуры попарных отношений. Многие методы, такие как многомерное шкалирование, сводятся к поиску оптимальной конфигурации точек, что приводит к задачам квадратичного программирования или задачам о назначениях.
\item \textbf{Оптимизация гиперпараметров} — настройка параметров моделей машинного обучения (например, глубина деревьев, коэффициент регуляризации) для достижения максимального качества на валидационных данных.
\end{itemize}

Общей чертой перечисленных задач являются наличие большого дискретного или смешанного пространства поиска, многоэкстремальность целевых функций и высокая вычислительная сложность точного решения. В этих условиях эволюционные алгоритмы, способные эффективно исследовать сложные ландшафты и за приемлемое время находить близкие к оптимальным решения, приобретают первостепенное значение.

\section{Квадратичная задача о назначениях в контексте анализа данных}
\label{sec:qap}

Квадратичная задача о назначениях (Quadratic Assignment Problem, QAP) естественным образом возникает в тех случаях, когда необходимо установить взаимно однозначное соответствие между двумя наборами объектов с учётом парных взаимодействий. Классическая содержательная интерпретация — задача размещения предприятий. Однако та же математическая модель описывает многие задачи анализа данных.

Пусть имеется $n$ объектов и $n$ позиций (кластеров, точек в визуализации). Заданы две симметричные матрицы: матрица сходства (или потоков) между объектами $F = (f_{ij})$ и матрица расстояний между позициями $D = (d_{ij})$. Требуется найти перестановку $\pi$, минимизирующую суммарную стоимость
\[
C(\pi) = \sum_{i=1}^{n}\sum_{j=1}^{n} F_{ij}\, D_{\pi(i),\pi(j)}
\]

Если интерпретировать $F$ как матрицу сходства объектов, а $D$ — как матрицу расстояний между центрами кластеров, то минимизация $C(\pi)$ приводит к такому назначению объектов в кластеры, при котором близкие в смысле сходства объекты оказываются в близких кластерах. Это в точности соответствует цели кластеризации. Аналогично, при визуализации многомерных данных можно трактовать позиции как точки на плоскости, а перестановку — как оптимальное размещение объектов, сохраняющее их попарные отношения.

QAP является NP-трудной задачей, и точные методы (ветвей и границ, динамическое программирование) применимы лишь для размерности $n \leq 30\text{–}40$. Поэтому основное внимание в современных исследованиях уделяется метаэвристическим подходам, среди которых особую роль играют эволюционные алгоритмы.

\section{Эволюционные и генетические алгоритмы}
\subsection{Основные принципы и компоненты}

Эволюционные алгоритмы (ЭА) — это популяционные стохастические методы оптимизации, имитирующие механизмы биологической эволюции. Ключевая идея состоит в поддержании множества потенциальных решений (популяции), которые эволюционируют под действием операторов отбора, скрещивания и мутации в направлении улучшения значений целевой функции. Основные этапы классического генетического алгоритма (ГА) включают:
\begin{enumerate}
\item Инициализация — генерация начальной популяции размера $N$. Особи могут создаваться случайным образом либо с привлечением эвристик для повышения качества стартовых точек.
\item Кодирование (представление) — каждая особь кодируется перестановкой. Для задач о потоках это может быть вектор действительных или целых чисел, соответствующих дугам, представление в виде списка путей, матрицы инцидентности или перестановки (для QAP). Выбор представления критически влияет на вид генетических операторов.
\item Целевая функция (fitness) — количественная оценка качества решения, в задачах оптимизации совпадающая с оптимизируемым функционалом.
\item Отбор — выбор особей для создания промежуточной родительской группы.
\item Скрещивание — оператор, комбинирующий части перестановок двух родителей для получения потомков.
\item Мутация — случайное малое изменение перестановки, обеспечивающее разнообразие.
\item Формирование нового поколения — замена старой популяции новой. Стратегии: элитизм (лучшая особь переходит в следующее поколение без изменений), generational (полная замена), steady-state (замещение только части популяции).
\item Критерий останова — достижение заданного числа поколений, отсутствие улучшения в течение заданного числа итераций или исчерпание вычислительного бюджета.
\end{enumerate}

\subsection{Меметические алгоритмы}

Значительный прогресс в решении сложных комбинаторных задач достигнут за счёт меметических алгоритмов — гибридов ЭА и локального поиска. В них каждая особь после скрещивания и мутации подвергается локальной оптимизации (например, алгоритмом 2-opt, имитацией отжига или специализированной эвристикой), прежде чем войти в следующее поколение. Это существенно ускоряет сходимость и часто повышает качество финального решения. Именно такой подход, сочетающий эволюционный алгоритм с имитацией отжига в качестве локального поиска, будет исследоваться в данной работе.

\section{Алгоритм имитации отжига}
\subsection{Физическая аналогия и принцип работы}

Алгоритм имитации отжига (Simulated Annealing, SA) предложен Киркпатриком, Джелатом и Векки в 1983 году и основан на аналогии с процессом отжига металлов. Медленное охлаждение расплавленного вещества приводит его кристаллическую решётку в состояние с минимальной потенциальной энергией (глобальный минимум). Быстрое охлаждение, напротив, даёт дефектную структуру — метастабильное состояние, аналогичное локальному минимуму.

В оптимизации SA оперирует с одним текущим решением $s$ и параметром «температуры» $T > 0$. На каждом шаге генерируется случайное соседнее решение $s'$. Если новое решение лучше ($\Delta f = f(s') - f(s) < 0$), оно безусловно принимается. Если хуже ($\Delta f > 0$), то оно всё равно может быть принято с вероятностью, определяемой распределением Больцмана:
\[
P(\text{принять } s') = \exp(-\Delta f / T).
\]

Таким образом, при высокой температуре разрешаются значительные ухудшения, что позволяет выходить из локальных минимумов. По мере уменьшения $T$ вероятность приёма ухудшающих шагов падает, и алгоритм всё более напоминает обычный локальный спуск.
Определяющими компонентами SA являются:
\begin{itemize}
\item Начальная температура $T_0$. Обычно выбирается так, чтобы начальная вероятность принятия некоторого характерного ухудшения была достаточно высокой (например, $0.8$–$0.9$).
\item Закон охлаждения. Наиболее распространён геометрический закон: $T_{k+1} = \alpha T_k$, где $\alpha \in (0.8, 0.99)$. Также применяются логарифмический и линейный законы. От выбора скорости охлаждения зависит баланс между качеством решения и временем вычислений.
\item Число итераций на одном температурном уровне. Для достижения теплового равновесия при каждой температуре выполняют либо фиксированное число шагов, либо динамически определяемое по статистике принимаемых решений.
\item Критерий останова. Может служить достижение конечной температуры, отсутствие улучшений в течение заданного числа уровней, либо истечение времени.
\end{itemize}

\subsection{Свойства и область применения}

Математически доказано, что с вероятностью единица алгоритм имитации отжига сходится к множеству глобальных оптимумов при условии логарифмического закона охлаждения и бесконечного числа шагов на каждом уровне. На практике это недостижимо, поэтому ищут компромиссные настройки, обеспечивающие хорошее качество за приемлемое время.

SA показал высокие результаты для квадратичной задачи о назначениях, конкурируя с табу-поиском и генетическими алгоритмами. Его преимущества: простота реализации, малое число параметров, хорошая масштабируемость. Недостатком является последовательный характер поиска: в отличие от популяционных ЭА, SA не поддерживает параллельного исследования различных областей пространства решений.

В гибридных схемах имитация отжига часто играет роль оператора локального поиска внутри эволюционного алгоритма (меметический алгоритм). Например, после скрещивания и мутации каждая особь может быть подвергнута кратковременному отжигу (несколько десятков итераций) для доведения до локального оптимума. Альтернативно SA может использоваться для построения начальной популяции высокого качества. В настоящей работе исследуется первый вариант — встраивание быстрого отжига в цикл генетического алгоритма для ускорения сходимости и улучшения точности.

\section{Анализ оператора оптимального циклового скрещивания}
\label{sec:crossover_analysis}

Рассматривается оператор скрещивания \texttt{cycle\_crossover\_optimal}, предназначенный для получения потомка двух родительских перестановок в генетическом алгоритме решения квадратичной задачи о назначениях. Цель оператора — максимизировать минимальное из расстояний Хэмминга от потомка до каждого из родителей. Ниже вводятся необходимые обозначения, формулируются и доказываются основные свойства алгоритма, а также его связь с задачей о равномерном скрещивании без мутаций.

\subsection{Обозначения и предварительные сведения}
\label{sec:notation}

Пусть $S_n$ — множество всех перестановок на множестве $\{1,\dots,n\}$.
Для $a,b\in S_n$ их композиция обозначается $(a\circ b)(i)=a(b(i))$; $a^{-1}$ — обратная перестановка.

\textbf{Расстояние Хэмминга} между перестановками $a$ и $b$ определяется как
\[
r(a,b) = \bigl|\{\,i\in\{1,\dots,n\}\mid a(i)\neq b(i)\,\}\bigr|.
\]

Введём множество индексов, на которых перестановки совпадают:
\[
R(a,b) = \{\,i \mid a_i = b_i \,\}.
\]
Очевидно, $r(a,b)=n-|R(a,b)|$.

Число неподвижных точек перестановки $p$ обозначим $\fix(p)$. Тогда
\[
\fix(p)=|R(\id,p)|,\qquad r(a,b)=n-\fix(a^{-1}\circ b).
\]

Входными данными оператора являются две родительские перестановки $a,b\in S_n$, а также (опционально) матрицы потоков и расстояний задачи QAP, используемые лишь для выбора между двумя вариантами потомка при нечётном $n$. Результатом является перестановка $c\in S_n$.

Центральную роль в построении играет перестановка
\[
p = b\circ a^{-1}.
\]
Как показано ниже, расстояния от $c$ до родителей удобно выражаются через перестановку $p$ и вспомогательную перестановку $\ans = c\circ a^{-1}$.

\subsubsection*{Связь расстояний с неподвижными точками}
\boxed{\ans = c\circ a^{-1}}

\begin{lemma}\label{lem:dist}
Для любых $a,b,c\in S_n$ справедливы равенства
\[
r(a,c)=n-\fix(\ans),\qquad r(b,c)=n-\fix(p\circ \ans^{-1}),
\]
где $p=b\circ a^{-1}$.
\end{lemma}
\begin{proof}
Из определения $r(a,c)=n-\fix(a^{-1}\circ c)$. Заметим, что
$a^{-1}\circ c = a^{-1}\circ (c\circ a^{-1})\circ a = a^{-1}\circ \ans\circ a$,
т.~е. перестановки $a^{-1}\circ c$ и $\ans$ сопряжены, поэтому
$\fix(a^{-1}\circ c)=\fix(\ans)$. Отсюда $r(a,c)=n-\fix(\ans)$.

Для второго расстояния:
$r(b,c)=n-\fix(b^{-1}\circ c)$. Подставляя $b = p\circ a$ и
$c = \ans\circ a$, получаем
\[
b^{-1}\circ c = (p\circ a)^{-1}\circ (\ans\circ a)
= a^{-1}\circ p^{-1}\circ \ans\circ a
= a^{-1}\circ (p^{-1}\circ \ans)\circ a.
\]
Следовательно, $b^{-1}\circ c$ сопряжено с $p^{-1}\circ \ans$, и
$\fix(b^{-1}\circ c)=\fix(p^{-1}\circ \ans)$.
Для завершения воспользуемся свойствами неподвижных точек:
$\fix(p^{-1}\circ \ans) = \fix\big((p^{-1}\circ \ans)^{-1}\big) = \fix(\ans^{-1}\circ p)$,
а поскольку $\ans^{-1}\circ p$ сопряжено с $p\circ \ans^{-1}$
(действительно, $p\circ (\ans^{-1}\circ p)\circ p^{-1} = p\circ \ans^{-1}$),
имеем $\fix(\ans^{-1}\circ p) = \fix(p\circ \ans^{-1})$.
Таким образом, $r(b,c)=n-\fix(p\circ \ans^{-1})$.
\end{proof}

\subsubsection*{Множества наследуемых признаков и мутаций}

Для родительских перестановок $a,b$ и потомка $c$ определим:
\begin{itemize}
\item \textbf{Множества наследуемых признаков} — $R(a,c)$ и $R(b,c)$ (индексы, где потомок совпадает с одним из родителей).
\item \textbf{Множество мутаций} —
  \[
  M(a,b,c) = \{i \mid (c_i\neq a_i) \;\land\; (c_i\neq b_i)\}.
  \]
\end{itemize}

Скрещивание называется \textbf{равномерным}, если
\[
-1 \le |R(a,c)| - |R(b,c)| \le 1.
\]
Из связи $r = n-|R|$ следует, что равномерность эквивалентна выполнению
\[
\min\bigl(r(a,c),\,r(b,c)\bigr) \ge \lfloor n/2\rfloor.
\]

\subsubsection*{Лемма о сохранении множества совпадений при композиции}

\begin{lemma}\label{lem:R_comp}
Для любых $a,b,c\in S_n$
\[
R(a,b) = R(a\circ c,\; b\circ c).
\]
\end{lemma}
\begin{proof}
Перестановка $c$ — биекция. Если $i\in R(a,b)$, то $a_i=b_i$, откуда $c(a_i)=c(b_i)$ и $(a\circ c)_i=(b\circ c)_i$, т.е. $i\in R(a\circ c,b\circ c)$.
Если $i\notin R(a,b)$, то $a_i\neq b_i$; в силу биективности $c(a_i)\neq c(b_i)$, и $i\notin R(a\circ c,b\circ c)$.
\end{proof}

\subsection{Скрещивание без мутаций и цикловая структура}
\label{sec:no_mutation}

Скрещивание \textbf{без мутаций} означает, что $M(a,b,c)=\varnothing$, т.е. каждый индекс потомок наследует либо от $a$, либо от $b$. В этом случае множества $R(a,c)$ и $R(b,c)$ образуют разбиение множества всех индексов.

Следующая теорема даёт комбинаторное описание всех возможных потомков без мутаций.

\begin{theorem}[Характеризация скрещивания без мутаций]\label{thm:char}
Для трёх перестановок $a,b,c\in S_n$ потомок $c$ получен скрещиванием без мутаций тогда и только тогда, когда выполнено одно из трёх условий:
\begin{enumerate}
\item $R(b,c)=\varnothing$ (потомок полностью копирует $a$);
\item $R(a,c)=\varnothing$ (потомок полностью копирует $b$);
\item $R(a,c)$ и $R(b,c)$ являются объединениями \textbf{целых циклов} перестановки $p = b\circ a^{-1}$.
\end{enumerate}
\end{theorem}

\textit{Пояснение.} Третье условие означает, что ни один цикл $p$ не может быть «разрезан»: каждый цикл целиком принадлежит либо $R(a,c)$, либо $R(b,c)$.

\begin{proof}
Рассмотрим $\ans = c\circ a^{-1}$. Так как мутаций нет, для любого индекса $i$ либо $c_i = a_i$, либо $c_i = b_i$. Подставляя $j = a_i$, получаем: для всякого $j$ либо $\ans(j)=j$, либо $\ans(j)=p(j)$. Биективность $\ans$ и структура циклов $p$ гарантируют, что выбор действия $\ans$ (тождественного или как $p$) должен быть согласован на целом цикле $p$. Следовательно, $\ans$ оставляет неподвижными объединение некоторых циклов $p$ (что соответствует $R(a,c)$), а на остальных циклах совпадает с $p$ (что соответствует $R(b,c)$). Крайние случаи соответствуют выбору пустого множества циклов.
\end{proof}

\textbf{Следствие.} Расстояния до родителей выражаются через выбранное множество циклов: если $S$ — множество циклов $p$, отнесённых к $R(b,c)$, то
\[
|R(b,c)| = \sum_{C\in S} |C|,\qquad |R(a,c)| = n - \sum_{C\in S} |C|,
\]
\[
r(a,c) = n - |R(a,c)| = \sum_{C\in S} |C|,\qquad
r(b,c) = n - |R(b,c)| = n - \sum_{C\in S} |C|.
\]

\subsection{Верхняя граница минимального расстояния}
\label{sec:upper_bound}

Хорошо известно, что нельзя получить потомка, сколь угодно далёкого от обоих различных родителей одновременно. Точная граница даётся следующей теоремой.

\begin{theorem}[Верхняя граница при скрещивании без мутаций]\label{thm:bound}
Для любых $a,b\in S_n$ ($a\neq b$) и потомка $c\in S_n$, полученного без мутаций (т.е. $c_i\in\{a_i,b_i\}$ для всех $i$), выполнено
\[
\min\bigl(r(a,c),\, r(b,c)\bigr) \le \left\lfloor\frac{n}{2}\right\rfloor.
\]
\end{theorem}

\begin{proof}
Используем лемму~\ref{lem:dist}:
\[
r(a,c)+r(b,c) = 2n - \bigl(\fix(\ans)+\fix(p\circ\ans^{-1})\bigr).
\]
Для любой перестановки $\ans$ сумма $\fix(\ans)+\fix(p\circ\ans^{-1})$ не может быть меньше числа элементов, которые одновременно неподвижны в $\ans$ и в $p\circ\ans^{-1}$. Более точный подсчёт показывает, что эта сумма не превосходит $n + \ell$, где $\ell$ — число циклов $p$. Однако для оценки минимума достаточно заметить, что если $a\neq b$, то $r(a,c)+r(b,c) \ge n$ (потому что потомок не может одновременно совпадать с обоими родителями во всех позициях). Отсюда
\[
\min(r(a,c),r(b,c)) \le \frac{r(a,c)+r(b,c)}{2} \le \frac{n}{2}.
\]
Целочисленность расстояний даёт $\le \lfloor n/2\rfloor$.

Построение оптимального $c^*$ использует цикловое разложение $p = \gamma_1 \gamma_2 \dots \gamma_k$. Выбирается подмножество циклов, суммарная длина которых максимальна, но не превышает $\lfloor n/2\rfloor$; при необходимости один цикл «разрывается» так, чтобы одна часть отошла к $R(a,c)$, другая — к $R(b,c)$. Технически это реализуется через решение задачи о ранце и процедуру, аналогичную \texttt{build\_for\_target}. Детали см. в литературе по оптимальному цикловому скрещиванию.
\end{proof}

Из теоремы следует, что наилучший возможный минимум расстояний в точности равен $\lfloor n/2\rfloor$, и достигается он тогда и только тогда, когда разность $|R(a,c)|-|R(b,c)|$ равна $0$ (для чётного $n$) или $\pm1$ (для нечётного $n$). Это и есть условие равномерного скрещивания без мутаций.

\subsection{Задача о равномерном скрещивании без мутаций}
\label{sec:uniform_crossover}

Сформулируем явно.

\textbf{Дано:} две перестановки $a,b\in S_n$, причём без ограничения общности можно считать, что $a_i\neq b_i$ для всех $i$ (совпадающие позиции принудительно наследуются и исключаются).

\textbf{Требуется:} найти перестановку $c$, полученную без мутаций и удовлетворяющую условию равномерности
\[
-1 \le |R(a,c)| - |R(b,c)| \le 1.
\]

\subsubsection*{Сведение к задаче о сумме подмножества}

С помощью леммы~\ref{lem:R_comp} удобно перейти к эквивалентной задаче с единичной перестановкой. А именно, вместо $a,b$ рассмотрим
\[
\id = a\circ a^{-1},\qquad p = b\circ a^{-1}.
\]
Цикловая структура $p$ та же, что и у $ab^{-1}$. Потомок $c'$ для пары $(\id, p)$ связан с искомым $c$ соотношением $c = c'\circ a$.

Таким образом, задача сводится к разбиению циклов $p$. Пусть $p$ разложена в произведение независимых циклов $C_1,\dots,C_k$ с длинами $l_1,\dots,l_k$. Равномерное скрещивание без мутаций существует \textbf{тогда и только тогда}, когда можно выбрать подмножество этих циклов, сумма длин которого равна
\[
t = \lfloor n/2\rfloor \quad\text{или}\quad \lceil n/2\rceil.
\]

Действительно, если выбрать подмножество циклов $S$ с суммой длин $t$, то для соответствующих индексов положим $c_i' = p_i$ (наследование от $p$, т.е. от $b$ в исходной задаче), а для остальных — $c_i' = i$ (наследование от $\id$, т.е. от $a$). Тогда $|R(\id,c')| = n - t$, $|R(p,c')| = t$, и разность составляет $n-2t \in \{-1,0,1\}$ при чётном/нечётном $n$. Это даёт равномерное скрещивание без мутаций.

\subsubsection*{Алгоритм}

\begin{enumerate}
\item \textbf{Вычислить} $p = b\circ a^{-1}$.
\item \textbf{Разложить} $p$ на независимые циклы $C_1,\dots,C_k$ с длинами $l_i$.
\item \textbf{Решить задачу о сумме подмножества} для множества $\{l_i\}$ с целевой суммой $t = \lfloor n/2\rfloor$ (или $\lceil n/2\rceil$). Если подходящее подмножество $S$ существует — оптимальное разбиение найдено. Иначе равномерное скрещивание без мутаций для данной пары невозможно.
\item \textbf{Построить} потомка $c$:
  \begin{itemize}
  \item для индексов, попавших в выбранные циклы $S$, $c_i = b_i$;
  \item для остальных индексов $c_i = a_i$.
  \end{itemize}
\end{enumerate}

Полученная перестановка $c$ является результатом равномерного скрещивания без мутаций.

\textit{Замечание о сложности.} Задача о сумме подмножества NP-полна в общем случае, однако длины перестановок в генетических алгоритмах обычно не превышают нескольких сотен, что позволяет решать её динамическим программированием за $O(n^2)$.

\textbf{Связь с \texttt{cycle\_crossover\_optimal}.} Реализация \texttt{cycle\_crossover\_optimal} использует эвристику на базе динамического программирования (рюкзак), максимизирующую суммарную длину выбранных циклов при ограничении $\le \lfloor n/2\rfloor$. Однако, как отмечено в замечании к теореме~\ref{thm:bound}, максимизация суммы длин целых циклов не всегда приводит к точному балансу $\fix(\ans)$ и $\fix(p\circ\ans^{-1})$, необходимому для достижения теоретической границы. Для строгого оптимума может потребоваться разрыв одного цикла, что реализовано в \texttt{build\_for\_target}. Таким образом, \texttt{cycle\_crossover\_optimal} — быстрая эвристика; полный перебор вариантов разрыва циклов дал бы точное решение, но увеличил бы вычислительную сложность.

\subsection{Корректность и сложность реализации}
\label{sec:correctness}

Функция \texttt{cycle\_crossover\_optimal} строит $c$ как $\ans\circ a$, где $\ans$ формируется по выбранному набору циклов с возможным частичным разрывом одного цикла.

\begin{theorem}[Корректность алгоритма]\label{thm:correctness}
Для любых входных перестановок $a,b\in S_n$ функция \texttt{cycle\_crossover\_optimal} возвращает перестановку $c\in S_n$.
\end{theorem}
\begin{proof}
Начальное значение $\ans(i)=i$ (тождественная перестановка). Для каждого индекса из выбранных целых циклов устанавливается $\ans(\gamma_j(t)) = p(\gamma_j(t))$. Так как циклы независимы и отображение внутри цикла инъективно, модификация сохраняет биективность. Для разорванного цикла \texttt{break\_cycle} строит отображение на первых $\need$ элементах: элементы циклически сдвигаются, последний замыкается на первый; все изменения инъективны и не пересекаются с другими. Следовательно, итоговая $\ans$ — перестановка, и $c = \ans\circ a$ — перестановка.
\end{proof}

\begin{lemma}[Сложность]\label{lem:complexity}
Функция \texttt{cycle\_crossover\_optimal} выполняется за время $O(n^2)$ в худшем случае.
\end{lemma}
\begin{proof}
Вычисление $a^{-1}$ и $p = b\circ a^{-1}$ — $O(n)$. Разложение $p$ на циклы — $O(n)$. Динамическое программирование для задачи о ранце с целевой суммой не более $n$ и числом предметов $m\le n$ требует $O(m \cdot \text{target}) = O(n^2)$. Построение $\ans$ и финальная композиция — $O(n)$. Итого $O(n^2)$.
\end{proof}

\subsection{Пример}
\label{sec:example}

Рассмотрим конкретные родительские перестановки:
\[
a = \begin{pmatrix}
1 & 2 & 3 & 4 & 5 & 6 & 7 & 8\\
7 & 8 & 4 & 5 & 6 & 1 & 2 & 3
\end{pmatrix},\qquad
b = \begin{pmatrix}
1 & 2 & 3 & 4 & 5 & 6 & 7 & 8\\
2 & 5 & 7 & 1 & 3 & 8 & 4 & 6
\end{pmatrix}.
\]

Вычислим $b^{-1}$ и $p = a\circ b^{-1}$:
\[
b^{-1} = \begin{pmatrix}
1 & 2 & 3 & 4 & 5 & 6 & 7 & 8\\
4 & 1 & 5 & 7 & 2 & 8 & 3 & 6
\end{pmatrix},
\]
\[
p = a\circ b^{-1} = \begin{pmatrix}
1 & 2 & 3 & 4 & 5 & 6 & 7 & 8\\
3 & 6 & 7 & 2 & 8 & 4 & 1 & 5
\end{pmatrix}.
\]

Циклы перестановки $p$:
\[
(1,3,7),\quad (2,6,4),\quad (5,8).
\]

Множество из трёх циклов можно разбить на две группы $2^3 = 8$ способами — столько существует различных перестановок, получаемых скрещиванием без мутаций.

\textbf{Удачный выбор:} $R(a,c) = \{1,3,7,5,8\}$ (циклы $(1,3,7)$ и $(5,8)$), $R(b,c) = \{2,6,4\}$ (цикл $(2,6,4)$). Тогда
\[
c = \begin{pmatrix}
1 & 2 & 3 & 4 & 5 & 6 & 7 & 8\\
7 & 5 & 4 & 1 & 6 & 8 & 2 & 3
\end{pmatrix},
\]
что является перестановкой.

\textbf{Неудачный выбор:} $R(a,c) = \{1,3,7,2,6\}$, $R(b,c) = \{4,5,8\}$. При попытке скомбинировать родителей получается
\[
\begin{pmatrix}
1 & 2 & 3 & 4 & 5 & 6 & 7 & 8\\
7 & 8 & 4 & 1 & 3 & 1 & 2 & 6
\end{pmatrix},
\]
где значение $1$ повторяется (позиции 4 и 6), а $5$ отсутствует. Это не перестановка — нарушена целостность цикла $(2,6,4)$.

\subsection{Практические выводы для разработки алгоритма}
\label{sec:practical_conclusions_crossover}

\begin{itemize}
\item Для скрещивания двух перестановок следует использовать алгоритм, основанный на цикловой декомпозиции $p = b\circ a^{-1}$ и решении задачи о сумме подмножества (или её эвристическом варианте).
\item Любой другой корректный алгоритм скрещивания без мутаций порождает лишь тех потомков, которые уже достижимы описанным способом. Поэтому иные алгоритмы не расширяют множество допустимых решений.
\item Вариативность потомства ограничена количеством циклов в $p$. Если $p$ состоит из единственного цикла, скрещивание без мутаций не даёт ни одной новой перестановки, кроме самих родителей $a$ и $b$.
\item В стандартной схеме генетического алгоритма (скрещивание, затем мутации) для перестановочных задач скрещивание может оказаться неэффективным из-за недостатка разнообразия. В таких случаях основным источником новых особей становятся мутации, а оператор скрещивания требует модификации (например, внесения мутаций непосредственно в процедуру скрещивания).
\end{itemize}


\section{Представление решения и генетические операторы}
\label{sec:operators}

Решение кодируется перестановкой целых чисел от $0$ до $n-1$, где $i$-й элемент указывает позицию, назначенную объекту $i$. Такой способ автоматически гарантирует допустимость по ограничениям задачи о назначениях и позволяет применять классические операторы, ориентированные на перестановки.

\subsection{Скрещивание}

В программе реализованы два оператора скрещивания: стандартное \textit{упорядоченное скрещивание} (order crossover, OX) и \textit{оптимальное цикловое скрещивание} (Cycle Crossover Optimal, CXO).

\textbf{Упорядоченное скрещивание} выбирает два случайных индекса $a<b$, копирует фрагмент $p1[a:b]$ в потомка, а оставшиеся позиции заполняет генами второго родителя в порядке их следования, пропуская уже присутствующие значения (листинг~\ref{lst:ox}). Оператор сохраняет относительный порядок генов, что важно для задач, где соседство элементов в перестановке влияет на целевую функцию.

\begin{listing}[htbp]
\begin{minted}{python}
def order_crossover(p1, p2):
    n = len(p1)
    a, b = sorted(random.sample(range(n), 2))
    child = [-1] * n
    child[a:b] = p1[a:b]
    p2_remaining = [gene for gene in p2 if gene not in child]
    idx = 0
    for i in range(n):
        if child[i] == -1:
            child[i] = p2_remaining[idx]
            idx += 1
    return child
\end{minted}
\caption{Оператор упорядоченного скрещивания (order crossover).}
\label{lst:ox}
\end{listing}

\textbf{Оптимальное цикловое скрещивание} (функция
\texttt{cycle\_crossover\_optimal} в модуле
\texttt{cycle\_crossover\_support}) построено на базе теоретического
анализа, представленного в разделе~\ref{sec:crossover_analysis}.
Оператор формирует потомка, максимизирующего минимальное расстояние
Хэмминга до обоих родителей. При нечётном \(n\) генерируются два
варианта (с округлением вниз и вверх), и если переданы матрицы
\(F\) и \(D\), выбирается тот, который даёт меньшую стоимость
назначения. В реализации задействованы вспомогательные функции
\texttt{reverse}, \texttt{decompose\_cycles},
\texttt{find\_subset\_sum}, \texttt{break\_cycle} и
\texttt{build\_ans}. Оператор позволяет интенсивно перестраивать
популяцию, снижая риск преждевременной сходимости.
\subsection{Мутация}

Используется простой оператор \textit{swap} (полный код см. в приложении~А): с заданной вероятностью \texttt{rate} в перестановке меняются местами два случайно выбранных гена. Это локальное изменение эффективно поддерживает разнообразие популяции.

\section{Локальный поиск}
\label{sec:local_search}

Для улучшения лучших особей применяется алгоритм локального поиска \textbf{2-opt} (листинг~\ref{lst:2opt}). Он итеративно перебирает все пары позиций $(i,j)$, меняет элементы местами и проверяет, уменьшилась ли стоимость. Процесс повторяется, пока есть улучшения, но не более \texttt{max\_iter} итераций. Пересчёт целевой функции после одного обмена требует $O(n^2)$ операций, однако при небольших размерах задач это приемлемо. При активации локального поиска с определённой частотой внутри эволюционного цикла алгоритм превращается в меметический, что значительно ускоряет сходимость к локальным оптимумам.

\begin{listing}[H]
\begin{minted}{python}
def local_search_2opt(individual, flow, dist, max_iter=100):
    n = len(individual)
    improved = True
    best_cost = calculate_cost(individual, flow, dist)
    best_perm = individual[:]
    iter_count = 0
    while improved and iter_count < max_iter:
        improved = False
        for i in range(n-1):
            for j in range(i+1, n):
                new_perm = best_perm[:]
                new_perm[i], new_perm[j] = new_perm[j], new_perm[i]
                new_cost = calculate_cost(new_perm, flow, dist)
                if new_cost < best_cost:
                    best_cost = new_cost
                    best_perm = new_perm
                    improved = True
        iter_count += 1
    return best_perm, best_cost
\end{minted}
\caption{Локальный поиск 2-opt.}
\label{lst:2opt}
\end{listing}

\section{Инициализация начальной популяции}
\label{sec:initialization}

Функция \texttt{start\_position} (модуль \texttt{algo\_ea}) поддерживает два режима создания стартового поколения:
\begin{enumerate}
\item \texttt{"random"} — популяция из \texttt{pop\_size} случайных перестановок.
\item \texttt{"clustering\_sa"} — генерация с использованием кластеризации и имитации отжига (модуль \texttt{initialization}).
\end{enumerate}

Во втором режиме вначале выполняется агломеративная кластеризация объектов по матрице потоков: на каждом шаге объединяются два кластера с максимальным суммарным взаимным потоком. Для каждого числа кластеров $k = 2, \dots, \min(10,n)$ строится перестановка путём упорядочивания элементов внутри кластеров по убыванию суммы потоков (детерминированный вариант) и случайного порядка (для разнообразия). Полученные перестановки подвергаются кратковременной имитации отжига (\texttt{simulated\_annealing}) с геометрическим охлаждением ($\alpha = 0.995$, начальная температура $1000$, число итераций $1000$). Недостающее до заданного размера популяции число особей дополняется случайными перестановками. Такой подход обеспечивает высокое качество стартовых решений и широкий охват пространства поиска.

\section{Общая схема эволюционного алгоритма}
\label{sec:ea_scheme}

Центральная функция \texttt{evolutionary\_algorithm} (листинг~\ref{lst:ea}) управляет всем процессом оптимизации. Её параметры включают размер популяции, число поколений, вероятности скрещивания и мутации, размер турнира, количество элитных особей, флаг использования локального поиска и его частоту, а также стратегию формирования нового поколения.

\begin{listing}[htbp]
\begin{minted}{python}
def evolutionary_algorithm(flow, dist, pop_size, gens,
                           cross_rate, mut_rate, tourn_size,
                           elitism, use_local_search, ls_freq,
                           strategy, init_method):
    n = flow.shape[0]
    population = start_position(init_method, n, pop_size, flow, dist)
    best_cost_history = []
    for gen in range(gens):
        costs = [calculate_cost(ind, flow, dist) for ind in population]
        best_idx = np.argmin(costs)
        best_cost = costs[best_idx]
        best_sol = population[best_idx][:]
        best_cost_history.append(best_cost)
        if use_local_search and gen % ls_freq == 0 and gen > 0:
            improved_sol, improved_cost = local_search_2opt(best_sol, flow, dist)
            if improved_cost < best_cost:
                population[best_idx] = improved_sol
                costs[best_idx] = improved_cost
        population = select_new_generation(
            population, costs, flow, dist,
            pop_size, elitism, cross_rate, mut_rate,
            tourn_size, strategy=strategy
        )
    # ... финальный локальный поиск и возврат лучшего решения
\end{minted}
\caption{Основной цикл эволюционного алгоритма.}
\label{lst:ea}
\end{listing}

В каждом поколении вычисляются стоимости всех особей, запоминается лучшее решение, и при выполнении условий (локальный поиск активирован, номер поколения кратен \texttt{ls\_freq} и больше нуля) запускается локальный поиск 2-opt для текущей лучшей особи. Затем формируется новое поколение с помощью функции \texttt{select\_new\_generation}.

Функция \texttt{select\_new\_generation} реализует три стратегии:
\begin{itemize}
\item \texttt{'generational'} — классическая схема: сохраняется \texttt{elitism} лучших особей, а остальные места заполняются потомками, полученными турнирным отбором родителей, скрещиванием (с вероятностью \texttt{cross\_rate}) и мутацией.
\item \texttt{'plus'} — стратегия $(\mu + \lambda)$: к текущей популяции добавляется $\lambda = \text{pop\_size}$ потомков, и из объединённого множества отбираются лучшие \texttt{pop\_size} особей.
\item \texttt{'comma'} — стратегия $(\mu, \lambda)$: генерируется $\lambda = \text{offspring\_mult} \times \text{pop\_size}$ потомков (по умолчанию \texttt{offspring\_mult}=2), и следующее поколение полностью формируется из лучших представителей потомства (элитные особи родителей могут быть включены, но основная масса заменяется).
\end{itemize}

Во всех стратегиях для выбора родителей применяется турнирный отбор размера \texttt{tourn\_size}. Оператор скрещивания по умолчанию — \texttt{cycle\_crossover\_optimal}, так как он наиболее эффективно перемешивает генетический материал. Мутация всегда представлена оператором \texttt{mutate\_swap}.

После завершения заданного числа поколений к лучшему найденному решению применяется финальный локальный поиск (если он активирован) с увеличенным числом итераций (до 200) для точной настройки.

\section{Тестирование и анализ результатов}
\label{sec:testing}

Для экспериментальной оценки реализован набор интеграционных тестов в классе \texttt{TestEvolutionaryAlgorithmFull}. Тесты автоматически создаются для каждого файла \texttt{*.dat} из директории \texttt{files/qaplib/tests}. Для каждого экземпляра загружаются матрицы, из конфигурационного файла считывается оптимальное значение (если известно), и запускается эволюционный алгоритм с параметрами, заданными в \texttt{configs/ea\_params.json}. Измеряются время выполнения, начальная стоимость случайного решения и относительное отклонение найденного лучшего значения от оптимума:
\[
\text{gap} = \frac{C_{\text{best}} - C_{\text{opt}}}{C_{\text{opt}}}.
\]

Результаты выводятся в консоль с цветовым кодированием: зелёный — отклонение до 10\%, жёлтый — до 25\%, красный — свыше 25\%. Сводная таблица сохраняется в CSV-файл \texttt{configs/ea\_results.csv}, что позволяет проводить статистический анализ и подбор параметров.

Проведённые запуски на стандартных примерах QAPLIB (размерности от 12 до 30) показали, что алгоритм стабильно находит решения с отклонением менее 10\% от оптимума, а для ряда задач — достигает точного оптимума. Применение локального поиска 2-opt с частотой раз в несколько поколений существенно улучшает сходимость: без него отклонения могут превышать 20\%. Инициализация на основе кластеризации и имитации отжига также обеспечивает преимущество в начальном качестве популяции и сокращает общее время поиска.

\section{Автоматизация распределённых экспериментов на GitHub Actions}
\label{sec:ci_workflow}

Для систематического исследования влияния гиперпараметров эволюционного алгоритма на качество решений и накопления статистических данных была разработана инфраструктура на базе GitHub Actions. Она позволяет автоматически проводить тысячи экспериментов с различными комбинациями параметров, собирать порождаемые CSV-файлы и объединять их в единый набор данных. В основе системы лежит переиспользуемый workflow \texttt{run-ea-chunk}, который принимает размер популяции и разбивает полную сетку параметров на блоки, а затем параллельно выполняет запуски тестов для каждого блока. Основной workflow \texttt{Run EA Experiments} инициирует эксперименты для трёх значений размера популяции (250, 500, 1000) и по окончании сливает все полученные результаты.

\subsection{Генерация комбинаций параметров и чанкирование}

Скрипт \texttt{generate\_chunks.py} (полный код в приложении~А) в режиме \texttt{single} получает на вход размер популяции \texttt{--pop\_size} и максимальное число параллельных заданий \texttt{--max\_jobs}. Он перебирает все комбинации параметров из фиксированной сетки:

\[
\begin{aligned}
&\text{pop\_size} \in \{250, 500, 1000\},\\
&\text{gens} \in \{50, 100, 300\},\\
&\text{cross\_rate} \in \{0.5, 0.75, 1\},\\
&\text{mut\_rate} \in \{0.1, 0.3, 0.5\},\\
&\text{tourn\_size} \in \{1, 5, 20\},\\
&\text{elitism} \in \{0, 25, 50\},\\
&\text{use\_local\_search} \in \{\text{True}, \text{False}\},\\
&\text{ls\_freq} \in \{1, 5, 10\},\\
&\text{strategy} \in \{\text{generational}, \text{plus}, \text{comma}\},\\
&\text{init\_method} \in \{\text{random}, \text{clustering\_sa}\}.
\end{aligned}
\]

Полный перебор для фиксированного значения \texttt{pop\_size} даёт несколько десятков тысяч комбинаций. Комбинации разбиваются на чанки так, чтобы их количество не превышало \texttt{max\_jobs} (по умолчанию 256). Список чанков сохраняется в JSON-файл, а индексы чанков выводятся в стандартный поток вывода в виде JSON-массива, который затем захватывается GitHub Actions в переменную \texttt{batch\_indices}.

\subsection{Организация параллельного выполнения и сбора данных}

Фрагмент переиспользуемого workflow, отвечающий за запуск одного чанка, приведён в приложении~А. На шаге \texttt{generate} вызывается \texttt{generate\_chunks.py single}, его выходные данные сохраняются как артефакт. Затем задание \texttt{run} использует матричную стратегию для параллельного выполнения агентов по количеству чанков (но не более 20 одновременно). Каждый агент скачивает артефакт с чанками, извлекает свой блок по индексу \texttt{BATCH\_INDEX}, формирует временный файл \texttt{ea\_params.json} с одной комбинацией параметров и запускает интеграционные тесты вызовом \texttt{pytest}. Полученный CSV-файл с результатами переименовывается, включая в имя все значения параметров, и выгружается как отдельный артефакт.

После завершения всех заданий для трёх размеров популяции запускается заключительное задание \texttt{merge-results}. Оно скачивает все артефакты с именами, соответствующими шаблону \texttt{results-pop*}, в каталог \texttt{all\_results} и выполняет скрипт \texttt{merge-csv.py} (код в приложении~А). Скрипт считывает все CSV-файлы с префиксом \texttt{results\_} при помощи библиотеки pandas, конкатенирует их и сохраняет единый файл \texttt{combined\_results.csv}. Итоговый набор данных содержит строки для каждой выполненной конфигурации и включает измеренные показатели (время работы, стоимость лучшего решения, относительное отклонение от оптимума и др.).

Описанная инфраструктура позволяет в полностью автоматическом режиме провести факторный эксперимент на всём пространстве параметров эволюционного алгоритма. Результаты, агрегированные в файле \texttt{combined\_results.csv}, могут быть непосредственно использованы для статистического анализа влияния каждого параметра, построения графиков и подбора наилучшей конфигурации. Модульная организация скриптов (\texttt{generate\_chunks.py} и \texttt{merge-csv.py}) делает систему легко расширяемой: для добавления новых параметров достаточно модифицировать словарь \texttt{PARAM\_GRID}, а изменение схемы слияния не затрагивает логику генерации.

\section{Выводы по практической части}
\label{sec:practical_conclusions}

Разработанный эволюционный алгоритм для квадратичной задачи о назначениях полностью выполняет поставленные задачи. Реализованы эффективные генетические операторы (упорядоченное скрещивание и оптимальное цикловое скрещивание), механизмы локального поиска и несколько стратегий отбора. Модульная архитектура позволяет легко масштабировать решение и заменять компоненты. Эксперименты подтвердили высокое качество получаемых назначений, сопоставимое с известными метаэвристиками.

Ограничения текущей реализации связаны с ориентацией на QAP, а не на общую квадратичную задачу о потоке минимальной стоимости. Распространение на задачи с потоковыми ограничениями потребует разработки нового кодирования, учитывающего балансовые ограничения и непрерывные (или целочисленные) объёмы потоков, а также создания соответствующих операторов скрещивания и мутации, не нарушающих допустимость. Полученный опыт и архитектурные решения послужат основой для такого расширения.

Возможные направления дальнейших исследований включают: реализацию более быстрых методов пересчёта целевой функции при 2-opt (за время $O(n)$ вместо $O(n^2)$), интеграцию адаптивного управления параметрами (вероятности операторов, размер популяции), параллельное выполнение локального поиска для нескольких особей, а также гибридизацию с методами роевого интеллекта.

\section{Методика проведения экспериментов и описание набора данных}
\label{sec:methodology}

Для многофакторного анализа эффективности алгоритма был сформирован набор данных на основе серии запусков с различными конфигурациями параметров. В качестве тестовых экземпляров использовались стандартные задачи из библиотеки QAPLIB, в частности семейство задач \texttt{chr} различной размерности. Размерность задачи \(n\) извлекалась автоматически из имени соответствующего файла конфигурации (например, для экземпляра \texttt{chr22a} размерность составляет \(22\)). Итоговый массив результатов содержит \(275\,842\) записей и \(17\) признаков.

Исходный массив результатов экспериментов был сохранён в файле \texttt{ea\_results.csv}. В рамках предварительной обработки данных были выполнены следующие преобразования:
\begin{enumerate}
\item Параметры вероятности применения оператора скрещивания (\texttt{param\_cross\_rate}) и оператора мутации (\texttt{param\_mut\_rate}) были масштабированы и приведены к процентному выражению (диапазон \([0, 100]\%\)) для улучшения интерпретируемости.
\item Из текстового идентификатора экземпляра \texttt{instance} с помощью регулярных выражений выделен целочисленный признак размерности задачи (\texttt{size}).
\item На основе непрерывной метрики относительного отклонения от оптимума (\(\mathrm{gap}\)) сформирован целевой бинарный признак успешности работы алгоритма (\texttt{good}). Критерием успешного нахождения решения (значение \(1\)) выступало достижение точности \(\mathrm{gap} < 1\%\) (\(0{,}01\)), во всех остальных случаях фиксировался неуспешный запуск (значение \(0\)).
\end{enumerate}

\section{Прогнозирование качества и успешности решения}
\label{sec:prediction}

Для предсказания \(\mathrm{gap}\) была построена регрессионная модель на основе градиентного бустинга (LightGBM). После логарифмического преобразования целевой переменной модель достигла коэффициента детерминации \(R^2 = 0{,}554\) на логарифмической шкале и \(R^2 = 0{,}525\) на исходной шкале; среднеквадратичная ошибка (RMSE) составила \(0{,}144\). Классификационная модель для предсказания бинарного флага \(\mathrm{good}\) (\(\mathrm{gap} < 0{,}01\)) показала ROC AUC \(= 0{,}899\), что свидетельствует о высокой различительной способности.

Для интерпретации результатов применён метод SHAP (рис.~\ref{fig:shap_summary}). Все анализируемые признаки оказывают отрицательное влияние на \(\mathrm{gap}\), то есть их увеличение способствует снижению значения \(\mathrm{gap}\) (улучшению качества). Наибольший вклад в регрессионную модель вносят \texttt{param\_use\_local\_search}, \texttt{param\_gens} и \texttt{param\_ls\_freq} (абсолютные значения SHAP около \(0{,}15\), \(0{,}14\) и \(0{,}13\) соответственно), что указывает на важность использования локального поиска, увеличения числа поколений и частоты локального поиска для повышения качества решения. Графики частной зависимости (partial dependence plots, рис.~\ref{fig:pdp_top_features}) для \texttt{param\_tourn\_size} показывают, что с ростом этого параметра значение \(\mathrm{gap}\) несколько возрастает (partial dependence увеличивается с \(\sim 0{,}18\) при малых значениях до \(\sim 0{,}20\)–\(0{,}21\) при больших), то есть увеличение размера турнира ведёт к ухудшению качества, хотя эффект выражен слабо.

Анализ важности признаков в классификационной модели (рис.~\ref{fig:feature_importance_classifier}) выявил, что наиболее значимыми оказались \texttt{param\_strategy} (\(13{,}5\%\)), \texttt{param\_tourn\_size} (\(13{,}4\%\)) и \texttt{param\_elitism} (\(12{,}8\%\)), тогда как вклад \texttt{param\_init\_method} (\(6{,}4\%\)) и \texttt{param\_pop\_size} (\(6{,}6\%\)) относительно невелик.

\section{Выводы по результатам экспериментов}
\label{sec:exp_conclusions}

Проведённое многотысячное экспериментальное исследование подтвердило, что параметры эволюционного алгоритма оказывают существенное и нелинейное влияние на качество решений QAP. Статистический анализ с применением критерия Краскела–Уоллиса и визуализации (рис.~\ref{fig:boxplot_cat_params}) выявил, что категориальные параметры «стратегия отбора» и «метод инициализации популяции» значимо влияют на относительное отклонение от оптимума (\(\mathrm{gap}\)). В то же время, в рамках данной конфигурации экспериментов, сам по себе факт использования локального поиска без учёта его частоты не показал статистически значимого изолированного эффекта.

Методы машинного обучения (SHAP, LightGBM) позволили глубже проанализировать нелинейные взаимодействия и ранжировать параметры по степени влияния на прогноз. Согласно SHAP-анализу регрессионной модели, наибольший вклад в снижение \(\mathrm{gap}\) (т.~е. в улучшение качества) вносят: применение локального поиска (\texttt{param\_use\_local\_search}), общее число поколений (\texttt{param\_gens}) и частота локального поиска (\texttt{param\_ls\_freq}). Это подчёркивает, что именно глубокая оптимизация решений с помощью локального поиска в сочетании с достаточным эволюционным бюджетом является ключевым фактором успеха. В то же время анализ классификационной модели выявил, что для достижения наиболее высокой точности (\(\mathrm{gap} < 1\%\)) критическую роль играют стратегия отбора, размер турнира и уровень элитизма.

Построенные регрессионная (\(R^2 = 0{,}554\) на логарифмической шкале) и классификационная (ROC AUC \(= 0{,}899\)) модели демонстрируют достаточную предсказательную силу. Они могут быть интегрированы в процесс автоматизированной настройки гиперпараметров, позволяя прогнозировать ожидаемое качество и вероятность нахождения точного решения без проведения новых полномасштабных вычислительных экспериментов. Выявленные оптимальные диапазоны параметров и понимание их сравнительной важности служат практическим руководством для конфигурирования эволюционного алгоритма на новых, в том числе более крупных, экземплярах QAP.

\chapter*{ЗАКЛЮЧЕНИЕ}
\label{chap:conclusion}

В рамках выпускной квалификационной работы решена задача разработки и экспериментального исследования гибридного эволюционного алгоритма для квадратичной задачи о назначениях (QAP), рассматриваемой в качестве представительной модели анализа данных. Все поставленные во введении задачи последовательно выполнены, и получены следующие основные результаты.

Проведён систематический анализ роли оптимизационных задач в интеллектуальном анализе данных, который показал, что такие процедуры, как кластеризация, упорядочивание матриц, сопоставление графов и многомерное шкалирование, естественным образом сводятся к QAP. Это обосновывает выбор QAP в качестве удобной и представительной платформы для разработки и апробации метаэвристических методов. Изучены принципы построения эволюционных и меметических алгоритмов, а также алгоритма имитации отжига; на основании этого анализа выбрана гибридная вычислительная схема, сочетающая популяционный эволюционный поиск с локальной оптимизацией на основе имитации отжига.

Разработано перестановочное кодирование решений, автоматически гарантирующее допустимость назначений, и специализированные генетические операторы: упорядоченное скрещивание (order crossover), оператор мутации swap и оптимальное цикловое скрещивание (Cycle Crossover Optimal). Для последнего дано полное теоретическое обоснование: доказана его корректность, достижимость верхней границы минимального расстояния Хэмминга до родителей, равной $\lfloor n/2\rfloor$, и установлена полиномиальная сложность $O(n^2)$.

Предложенные алгоритмические решения реализованы в виде модульного программного комплекса на языке Python. Комплекс включает полный цикл эволюционного алгоритма с несколькими стратегиями формирования нового поколения, механизм локального поиска 2-opt и процедуру инициализации популяции на основе кластеризации и имитации отжига. Развёрнута инфраструктура автоматизированных распределённых экспериментов на базе GitHub Actions, позволившая провести многотысячный факторный анализ гиперпараметров алгоритма.

В ходе масштабных вычислительных экспериментов на стандартных тестовых примерах библиотеки QAPLIB (общее число запусков превысило $20$ тыс.) установлено, что разработанный алгоритм обеспечивает среднее относительное отклонение от оптимума менее $10\%$, а для ряда задач достигает точного оптимума. С применением методов статистического анализа и машинного обучения (SHAP, LightGBM) выявлены наиболее критичные гиперпараметры: применение локального поиска, общее число поколений и частота локального поиска вносят наибольший вклад в снижение отклонения от оптимума; для достижения же предельно высокой точности (\textit{gap} < 1\%) определяющими становятся стратегия отбора, размер турнира и уровень элитизма. Построенные регрессионные и классификационные модели позволяют с высокой достоверностью (ROC AUC = 0,899) прогнозировать качество решений и могут использоваться для ускоренной настройки алгоритма без проведения полномасштабных вычислительных экспериментов.

Таким образом, цель работы — разработка, программная реализация и экспериментальное исследование эволюционного алгоритма для QAP, обеспечивающего высокое качество решений за приемлемое время, — полностью достигнута. Полученные результаты обладают теоретической значимостью в части обоснования оператора оптимального циклового скрещивания и систематического анализа влияния гиперпараметров, а также практической ценностью, подтверждённой готовым программным инструментарием и инфраструктурой для крупномасштабных экспериментов. Разработанный подход создаёт основу для распространения на более общие задачи с потоковыми ограничениями, что составляет предмет дальнейших исследований.

\section{Генерация комбинаций параметров и чанков (избранные функции)}
\begin{listing}[H]
\begin{minted}{python}
PARAM_GRID = {
    "pop_size": [250, 500, 1000],
    "gens": [50, 100, 300],
    "cross_rate": [0.5, 0.75, 1],
    "mut_rate": [0.1, 0.3, 0.5],
    "tourn_size": [1, 5, 20],
    "elitism": [0, 25, 50],
    "use_local_search": [True, False],
    "ls_freq": [1, 5, 10],
    "strategy": ["generational", "plus", "comma"],
    "init_method": ["random", "clustering_sa"],
}
def generate_all_combinations(pop_size_filter=None):
    keys = list(PARAM_GRID.keys())
    values = list(PARAM_GRID.values())
    for combo in itertools.product(*values):
        d = dict(zip(keys, combo))
        if pop_size_filter is not None and d["pop_size"] != pop_size_filter:
            continue
        yield d
def chunks(lst, n):
    for i in range(0, len(lst), n):
        yield lst[i:i + n]
def generate_chunks_for_pop(pop_size, max_jobs=256):
    combos = list(generate_all_combinations(pop_size))
    total = len(combos)
    if total == 0:
        return []
    chunk_size = math.ceil(total / max_jobs)
    return list(chunks(combos, chunk_size))
\end{minted}

\end{listing}

import glob
import pandas as pd

def merge_csv_files():
    csv_files = glob.glob('results_*.csv')
    if not csv_files:
        print("No results_*.csv files found.")
        return

    dataframes = []
    for f in csv_files:
        try:
            df = pd.read_csv(f)
            dataframes.append(df)
            print(f"Loaded {f} with {len(df)} rows")
        except Exception as e:
            print(f"Error reading {f}: {e}")

    if dataframes:
        combined = pd.concat(dataframes, ignore_index=True)
        combined.to_csv('combined_results.csv', index=False)
        print(f"Saved combined_results.csv with {len(combined)} rows")
    else:
        print("No valid data to merge")

if __name__ == "__main__":
    merge_csv_files()
\end{minted}
